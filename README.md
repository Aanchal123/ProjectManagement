## IS 594 – Project Management

This repository contains coursework and project artifacts developed for IS 594: Project Management.
It was used to organize assignments, maintain final project deliverables, and document work completed over the course of the term.

The repository reflects structured organization and incremental updates to support project management practices discussed in class.

## Repository Structure
Assignments/

Contains course assignments, templates, and supporting artifacts completed during the semester.

Lecture Notes/

Includes brief summaries and notes reflecting key project management concepts covered in lectures and discussions.

Final_paper/

Contains final project deliverables, including the research paper and presentation materials.

Reflection/

Contains the one-page report summarizing the experience of creating and maintaining this GitHub repository.

## Repository Maintenance

This repository was maintained throughout the term to track progress, manage versions of key deliverables, and consolidate course materials in a single workspace. Updates were made as work progressed on assignments and the final project.

## Purpose

The purpose of this repository is to demonstrate the use of GitHub as a lightweight project management and documentation tool for academic work, consistent with course expectations.
